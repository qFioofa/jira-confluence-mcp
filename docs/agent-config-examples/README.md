# Примеры конфигураций

| Файл | Назначение |
|---|---|
| `jira-cld.cloud.yml` | Jira + Confluence Cloud, два проекта |
| `jira-cld.dc.yml` | Jira + Confluence Data Center, PAT |
| `jira-cld.minimal.yml` | Минимальный конфиг для одного проекта |
| `opencode.local.json` | Один проект в opencode (stdio) |
| `opencode.remote.json` | Один проект в opencode (HTTP URL, без токена) |
| `opencode.multi-project.json` | Несколько изолированных проектов (stdio) |

Пути и токены в примерах — заполнители. Замените домены, ключи проектов и `token_ref`
на свои. Секреты в YAML не хранятся.
